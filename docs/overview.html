1 · DirectSTUN finds a route through home routers (most cases)
2 · RelayTURN server forwards traffic for strict NATs (hotspots, CGNAT)
3 · No internetcopy-paste codes on a LAN, or Tailscale
  • 30 Hz binary snapshots (20 bytes per player) on an unreliable channel; events (kills, chat, buys) on a reliable one
  • Others drawn 100 ms behind, interpolated, for smooth movement
  • Shooter-favoured hits: you claim what you hit, the host sanity-checks range and state
  • Host decides deaths, respawns, explosives, pickups, seats, streak rewards
  • Lobby: ready-up, kick, chat, skins by rank, ping, Direct / LAN / Relayed shown

Key decisions

  • One offline file: three.js, font and code inlined; zero requests in single-player
  • Everything generated: audio, music, camos, soldiers built in code
  • Hybrid bullets: hitscan with falloff + penetration; snipers fly with drop
  • Host-authoritative P2P: free, no server to run, low lag
  • Respawn time never changes: the kill cam fits inside it
  • Real gun names by default, fictional toggle; original map and mode names

Build & quality loop

  • → build-standalone (esbuild + inlining) → one HTML
  • → headless Chromium tests: regression of every mode × map, multiplayer with 2–16 pages, wall + spawn audits, fit at 4 screen sizes, screenshots reviewed
  • → ship: commit, copy HTML, zip with history
  • Target: 60 fps on a typical laptop, fast load
